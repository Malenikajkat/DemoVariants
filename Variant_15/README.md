
```bash

psql -U postgres -c "CREATE DATABASE stomatologiya;"

psql -U postgres -d stomatologiya -f task2_db/001_create_tables.sql
```

## Задание 1: ER-диаграмма

ER-диаграмма содержит 12 сущностей (user_account не соединён):
- `customer` — Покупатели
- `product` — Продукция
- `material` — Материалы
- `tech_operation` — Технические операции
- `price` — Цены
- `user_account` — Пользователи (изолированная таблица)
- `customer_order` — Заказы покупателей
- `customer_order_detail` — Детали заказов покупателей
- `production_order` — Производственные заказы
- `production_order_material` — Материалы в производственных заказах
- `production_order_operation` — Операции в производственных заказах
- `specification` — Спецификации
- `cost_calculation` — Расчёт стоимости

**Формат**: PDF — `task1_er_diagram/er_diagram_variant15.pdf`

## Задание 3: SQL-запрос

### Расчёт стоимости заказов

Формула:
```
Полная_стоимость = Σ(Количество × (Σ(Норма_материала × Цена) + Σ(Норма_времени × Стоимость_операции)))
```

Запрос использует CTE (Common Table Expressions) для пошагового расчёта.

## Задание 5: API

### Эндпоинт GET /api/notes

Возвращает все заметки из таблицы `notes` в формате JSON.

#### Формат ответа:

```json
[
    {
        "id": 1,
        "title_user": "Конференция ИТ - user25",
        "content": "Не забыть подготовить презентацию...",
        "formatted_date": "15.03.2027"
    }
]
```

#### HTTP-статусы:
- **200 OK** — успешно (или пустой массив `[]`)
- **500 Internal Server Error** — ошибка БД

### Запуск API

```bash
python src/api_server.py
```

## PyCharm: Настройка Python

Убедитесь, что PyCharm использует **Python 3.11**, а не Python 2.7:

1. **File → Settings → Project → Python Interpreter**
2. Нажмите на шестерёнку → **Add...**
3. Выберите **System Interpreter**
4. Укажите путь к Python 3.11 (например: `C:\Python311\python.exe`)
5. Нажмите **OK**

Проверить версию Python:
```bash
python --version
# Должно быть: Python 3.11.x
```
