### Цель

Оценка умения осуществлять разработку тестовых наборов и тестовых сценариев для программного обеспечения.

### Исходные данные

В базе данных PostgreSQL создана таблица `notes`:

```sql
CREATE TABLE notes (
    id SERIAL PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    content TEXT,
    id_user INTEGER REFERENCES users(id),
    created_at TIMESTAMP DEFAULT NOW()
);
```

Таблица заполнена тестовыми данными (не менее 5 записей).

API-эндпоинт: `GET /notes` — возвращает список заметок с обработанными данными.

#### Часть 2. Автоматизация тестирования (Flask + pytest)

1. Создать тестовый скрипт `test_api_automation.py`:
   - Использовать библиотеку `requests` для отправки HTTP-запросов
   - Проверить статус-коды ответов
   - Валидировать структуру JSON-ответа
   - Зафиксировать результат в консольном выводе

2. Использовать `pytest` для организации тестов:

```python
import pytest
import requests

BASE_URL = "http://localhost:5000/api"

def test_get_notes_status():
    """TC-01: Проверка статуса 200"""
    response = requests.get(f"{BASE_URL}/notes")
    assert response.status_code == 200

def test_get_notes_json_format():
    """TC-02: Проверка формата JSON"""
    response = requests.get(f"{BASE_URL}/notes")
    assert response.headers.get("Content-Type") == "application/json"

def test_get_notes_fields():
    """TC-03: Проверка наличия обязательных полей"""
    response = requests.get(f"{BASE_URL}/notes")
    data = response.json()
    required_fields = ["id", "title_user", "content", "formatted_date"]
    for note in data:
        for field in required_fields:
            assert field in note, f"Отсутствует поле: {field}"

def test_get_notes_date_format():
    """TC-05: Проверка формата даты"""
    response = requests.get(f"{BASE_URL}/notes")
    data = response.json()
    import re
    date_pattern = re.compile(r"^\d{2}\.\d{2}\.\d{4}$")
    for note in data:
        assert date_pattern.match(note["formatted_date"]), \
            f"Неверный формат даты: {note['formatted_date']}"
```
